# 仮定と公理

`ASSUME-01`：GRHを明示的に仮定した定理と無条件定理を区別する。未証明の解析的入力を仮定する中間定理は、条件付きの成果として前提を明示する。未証明入力を仮定しながら無条件と説明する場合は `block` とする。

`ASSUME-02`：定理が依存する公理を `#print axioms` 等で確認し、`sorry` に由来する未許可の公理や独自の未許可公理があれば `block` とする。問題文を示すComparatorの課題側の `sorry` は証明の完成と扱わず、解答側を独立に検査する。

`ASSUME-03`：実質的な証明課題を仮定や構造体フィールドに移しただけで解決済みと主張する場合は `block` とする。中間インターフェースとして未証明の入力を明示する場合は、そのまま残課題として扱う。

Lean公理への依存と、定理の型に明示した数学的仮定は別々に監査する。
