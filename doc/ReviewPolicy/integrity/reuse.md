# 既存APIの再利用

`REUSE-01`：変更に必要なMathlibとPseudoPrimeの既存定理・定義を検索し、同じ契約の実装がないか確認する。再利用には仮定、結論、依存、利用側での使いやすさを含めて判断する。

`REUSE-02`：明白な重複によって成果の正確な評価やAPIの一貫性が損なわれる場合は具体的な既存宣言を示す。重大な場合は `block` とし、通常の改善は `request_changes` とする。所有者移設によって重複を解消する場合は、[一般化と所有者](../architecture/generality-ownership.md) の規準に従って対象ごとに審査する。
