# 上界の存続

`BOUND-LIFE-01`：上界を比較するときは、対象、仮定、適用域、端点、整数への丸め、点ごとか累積かを一つの契約として確認する。異なる仮定や範囲で成り立つ結果を、数値の大小だけで置き換えない。[定量上界](quantitative-bounds.md) の比較・検証規準も適用する。

`BOUND-LIFE-02`：現行の上界に支配された終端定理と、現行定理の証明に使う定義・補題・認証を区別する。終端が採用されないことだけを理由に、その証明核を削除しない。利用側と依存経路を調べてから存続を判断する。

`BOUND-LIFE-03`：歴史的比較は現行の証人定理に依存してよい。現行の証人定理が歴史的比較に依存している場合は、現行の証明を独立させて逆向きの依存を解消する。

`BOUND-LIFE-04`：旧結果を残す場合は、独立した用途、仮定や適用域の優位、または説明上の役割を記す。廃止を検討するときは置換先と比較の証拠を確認する。

## 候補台帳

存続や廃止の候補について、完全修飾名、ファイル、契約、置換先、比較証拠、利用側、属性、root閉包への所属、保持理由または廃止条件を記録する。属性には宣言の公開や振る舞いに関係する属性を含める。台帳はレビューのための情報であり、自動判定だけで削除を決めない。
