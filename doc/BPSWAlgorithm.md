# BPSWと強化版の定義・理論・実装手順

BPSWは、底2の強Miller–Rabin検査と、Selfridgeの方法でパラメータを選ぶ強Lucas検査を組み合わせた確率的素数性テストである。Baillie・Fiori・Wagstaffの強化版は、さらにLucas-V条件と、パラメータ $Q$ に対するEuler条件を検査する。

この文書では通常版にもMethod A*を使う。必要な記号、合同式、パラメータ探索、更新式、停止条件をここで定義し、末尾に単独で実行できるPython実装を示す。本文は論文 *Strengthening the Baillie–PSW primality test* の第2・3・6節と付録を中心に、公開参考実装の処理を説明する。

## 手順の全体像

通常版と強化版は次の順に処理する。各項目では、検査対象の整数 $n$ をどう判定するかを示す。実装は「素数ではない」または「合成数」と判定したら `False` を返して終了する。2の場合と、必要な検査をすべて通過した場合は `True` を返す。`True` は「おそらく素数」を意味し、素数性を保証する返り値ではない（2は素数と確定している）。強化版では、強Lucas条件に成功した後も追加検査に必要な計算を続ける。

- 入力を処理する。 $n = 2$ は素数と判定して終了する。$n < 2$ は素数ではないと判定し、2より大きい偶数は合成数と判定する。以後は奇数 $n \ge 3$ を扱う。[入力と判定結果](#input)
- 底2の強Miller–Rabin条件を検査する。 $n-1$ を奇数と2の冪の積に分解し、法累乗と平方の列を調べる。条件を満たさなければ $n$ は合成数と判定する。[MRの手順](#mr-procedure)
- 平方数かどうかを調べる。 整数平方根で平方数と分かったら、$n$ は合成数と判定する。[平方数と探索の停止](#square-and-termination)
- Selfridge候補を探索する。 $D = 5,-7,9,-11,\ldots$ の順にJacobi記号を調べ、最初の $J(D,n)=-1$ を選ぶ。$n$ の非自明因子を検出したら、$n$ は合成数と判定する。[候補と因子検出](#selfridge-scan)・[Jacobi記号の計算](#jacobi)
- Method A*でパラメータを選ぶ。 $D=5$ なら $(P,Q)=(5,5)$、それ以外なら $(P,Q)=(1,(1-D)/4)$ とする。[パラメータの選択](#parameters)
- Lucas計算を初期化する。 $n+1=2^{s_+}d_+$ と分解し、$(U_{d_+},V_{d_+},Q^{d_+})\bmod n$ を二進法で求める。[リュカ数列の定義](#lucas-definition)・[素数に対する合同式](#lucas-prime-congruences)・[共有する3つの値](#lucas-binary)・[法の下での2除算](#modular-halving)
- 強Lucas条件を検査する。 $U_{d_+}=0$ または $0 \le r < s_+$ のいずれかで $V_{2^r d_+}=0$ となるか調べる。どちらも成り立たなければ $n$ は合成数と判定する。通常版は条件を満たしたら、$n$ は確率的素数と判定して終了する。強化版は計算を続ける。[強Lucas条件](#strong-lucas)・[通常版の手順](#standard-procedure)
- 強化版ではLucas-V条件を検査する。 強条件の成功を記録しながら倍加を続け、$V_{n+1}\equiv2Q\pmod n$ を調べる。この条件を満たさなければ $n$ は合成数と判定する。[追加条件](#enhanced-conditions)・[最後の倍加と不変条件](#enhanced-loop)
- 強化版ではEuler条件を検査する。 最後の倍加で保持した $Q^{(n+1)/2}$ と $QJ(Q,n)$ を法 $n$ で比較する。一致しなければ $n$ は合成数と判定する。すべての条件を満たしたら、$n$ は確率的素数と判定して終了する。[Euler条件](#enhanced-conditions)・[独立したgcd検査を省ける理由](#q-coprime)

全体をコードで確認する場合は [単独で実行できるPython実装](#python-implementation)、値の変化を追う場合は [素数7の計算例](#example-seven) を参照する。

<a id="input"></a>

## 1. 入力と判定結果

入力は整数 $n$ である。最初に $n = 2$ なら素数と判定して `True` を返す。$n < 2$ なら素数ではないと判定し、2より大きい偶数なら合成数と判定して、どちらも `False` を返す。以後は奇数 $n \ge 3$ を扱う。

以後の説明で「受理」は、その検査の条件を満たすことを意味する。「棄却」は、条件を満たさないことを意味する。BPSW全体は、必要な検査をすべて通過した奇数を確率的素数と判定して `True` を返す。途中の検査で失敗した奇数は合成数と判定して `False` を返す。素数は必ずすべての検査を通過するため、この合成数判定は確定的である。任意精度の整数について、`True` から素数性が従うという一般定理はここでは用いない。

確率的素数という名称でも、以下の手続きに乱数はない。同じ入力には常に同じ底とLucasパラメータを使う。擬素数とは、対応する検査を通過する合成数をいう。

論文は、Method A*による通常版について $n < 2^{64}$ の合成数をすべて棄却する計算結果を報告している。これは論文の有限範囲の計算結果であり、この文書の実装をその範囲で全数検証したという意味ではない。強化版の反例が知られていないという記述も、論文執筆時点の報告として扱う。

<a id="jacobi"></a>

## 2. 算術の約束とJacobi記号

$x \bmod n$ は、$x$ と合同で $0 \le r < n$ を満たす剰余 $r$ とする。負の $Q$ や $D$ もこの規則で処理する。$\gcd(a,n)$ は最大公約数、$v_2(m)$ は正整数 $m$ に含まれる因子2の個数である。したがって $m = 2^{v_2(m)}d$ と書くと $d$ は奇数になる。

奇素数 $p$ に対するLegendre記号 $\left(\frac{a}{p}\right)$ は、$p \mid a$ なら0、$a$ が法 $p$ の非零平方剰余なら1、非平方剰余なら $-1$ である。正の奇数 $n = \prod_i p_i^{e_i}$ に対するJacobi記号を

$$
J(a,n) = \left(\frac{a}{n}\right)
= \prod_i \left(\frac{a}{p_i}\right)^{e_i}
$$

と定義する。$J(a,1) = 1$ とする。素因数分解は定義に使うだけで、実際の計算には不要である。

Jacobi記号は $-1,0,1$ のいずれかであり、$J(a,n) = 0$ と $\gcd(a,n) > 1$ は同値である。$n$ が合成数の場合、$J(a,n) = 1$ でも平方剰余とは限らない。

計算には次の規則を使う。

$$
J(ab,n) = J(a,n)J(b,n),\qquad
J(a,n) = J(a \bmod n,n),
$$

$$
J(-1,n) = (-1)^{(n-1)/2},\qquad
J(2,n) = (-1)^{(n^2-1)/8}.
$$

互いに素な正の奇数 $a,n$ に対する平方剰余の相互法則は

$$
J(a,n)J(n,a) = (-1)^{((a-1)/2)((n-1)/2)}
$$

である。互いに素でない場合も、交換時の同じ符号規則を使える。両方の記号が0になるためである。分子の因子2を取り除いて符号を更新し、奇数の分子と分母を交換して剰余を取る。Euclidの互除法と同じ形で値を求められる。

## 3. 底2の強Miller–Rabin検査

### 3.1 定義

$n-1 = 2^{s_-}d_-$、$d_-$ は奇数、$s_- = v_2(n-1)$ とする。底 $a$ の強Miller–Rabin受理条件は

$$
a^{d_-} \equiv 1 \pmod n
\quad\lor\quad
\exists j \in \mathbb{N},\quad
j < s_- \land a^{2^j d_-} \equiv -1 \pmod n
$$

である。BPSWでは $a = 2$ を使うので、奇数 $n \ge 3$ に対して底は非零で $n$ と互いに素になる。

Fermatの小定理は、奇素数 $n$ と $n$ と互いに素な底 $a$ に対して $a^{n-1} \equiv 1 \pmod n$ を与える。素数の法では $x^2 = 1$ の根は $1,-1$ の2個だけである。$a^{d_-}$ から繰り返し平方し、初めて1になる直前を調べると、上の強い条件が従う。

強条件を満たせばFermat条件も満たす。初項が1ならその後も1であり、途中で $-1$ になれば次の平方で1になるからである。合成数の法には別の平方根があり得るため、Fermat条件だけを満たす合成数の一部を強条件で除ける。

<a id="mr-procedure"></a>

### 3.2 手順

まず $t = 2^{d_-} \bmod n$ を二進累乗法で求める。二進累乗法では初期値を1とし、指数のビットを上位から読んで毎回平方する。ビットが1ならさらに底を掛け、各更新で法を取る。$t = 1$ なら受理する。それ以外では $j = 0,\ldots,s_- - 1$ の順に $t = n-1$ を調べ、見つかれば受理する。次の検査が残る場合だけ $t \leftarrow t^2 \bmod n$ と更新する。最後の検査にも失敗したら棄却する。

検査対象は $j < s_-$ に限る。最後にもう1回平方して指数 $n-1$ を作る処理は、強条件の判定には不要である。特に $s_- = 1$ なら、初項を1と $-1$ と比較するだけで終わる。

## 4. Lucas数列と素数に対する合同式

<a id="lucas-definition"></a>

### 4.1 定義

整数 $P > 0,Q$ に対して判別式を $D = P^2 - 4Q \ne 0$ とする。Lucas数列は

$$
U_0 = 0,\quad U_1 = 1,\qquad
V_0 = 2,\quad V_1 = P,
$$

$$
U_k = PU_{k-1} - QU_{k-2},\qquad
V_k = PV_{k-1} - QV_{k-2}\quad(k \ge 2)
$$

で定義する。パラメータを明示するときは $U_k(P,Q),V_k(P,Q)$ と書く。

$x^2-Px+Q$ の根を $\alpha,\beta$ とすると、$\alpha+\beta=P$、$\alpha\beta=Q$、$\alpha-\beta=\sqrt D$ であり、

$$
U_k = \frac{\alpha^k-\beta^k}{\alpha-\beta},\qquad
V_k = \alpha^k+\beta^k
$$

となる。この表示は理論の説明に使う。実装では平方根や拡大体を計算せず、整数の更新式を使う。

<a id="lucas-prime-congruences"></a>

### 4.2 素数に対する命題

奇素数 $p$ に対し $\gcd(p,QD) = 1$ とし、$\varepsilon = J(D,p)$、$\delta = p-\varepsilon$ と置く。このとき

$$
U_\delta \equiv 0 \pmod p,\qquad
V_\delta \equiv 2Q^{(1-\varepsilon)/2} \pmod p,
$$

$$
U_p \equiv \varepsilon \pmod p,\qquad
V_p \equiv P \pmod p
$$

が成り立つ。

理由は有限体でのFrobenius写像にある。$D$ が平方剰余なら両根は $\mathbb{F}_p$ にあり、$\alpha^p=\alpha,\beta^p=\beta$ となる。非平方剰余なら2次拡大体で $\alpha^p=\beta,\beta^p=\alpha$ となる。後者では $\alpha^{p+1}=\beta^{p+1}=Q$ なので、上の式は $U_{p+1}=0,V_{p+1}=2Q$ になる。

BPSWでは必ず $J(D,n)=-1$ となるパラメータを選び、次の2条件を使う。

| 名称 | 受理条件 |
|---|---|
| Lucas条件 | $U_{n+1} \equiv 0 \pmod n$ |
| Lucas-V条件 | $V_{n+1} \equiv 2Q \pmod n$ |

これらの条件を満たす合成数が、それぞれLucas擬素数、Lucas-V擬素数である。

<a id="strong-lucas"></a>

### 4.3 強Lucas条件

$n+1 = 2^{s_+}d_+$、$d_+$ は奇数、$s_+ = v_2(n+1)$ とする。強Lucas条件は

$$
U_{d_+} \equiv 0 \pmod n
\quad\lor\quad
\exists r \in \mathbb{N},\quad
r < s_+ \land V_{2^r d_+} \equiv 0 \pmod n
$$

である。MRの分解は $n-1$、Lucasの分解は $n+1$ に対して行う。

恒等式 $U_{2k}=U_kV_k$ を繰り返すと

$$
U_{n+1} = U_{d_+}\prod_{r=0}^{s_+-1}V_{2^r d_+}
$$

となる。奇素数の法では積が0なら少なくとも1因子が0なので、前節の命題から強Lucas条件が従う。逆に強条件なら上の積が0になるので、合成数の法でも通常のLucas条件を満たす。合成数の法では、積が0でもどの因子も0でない場合があるため、通常条件から強条件への逆は一般には使えない。

## 5. SelfridgeのMethod AとA*

<a id="selfridge-scan"></a>

### 5.1 候補と因子検出

絶対値 $i = 5,7,9,11,\ldots$ を昇順に調べ、

$$
D(i) =
\begin{cases}
i & i \equiv 1 \pmod 4,\\
-i & i \equiv 3 \pmod 4
\end{cases}
$$

とする。したがって候補は $5,-7,9,-11,13,-15,\ldots$ であり、常に $D \equiv 1 \pmod 4$ になる。

最初に $J(D,n)=-1$ となる候補を選ぶ。$J(D,n)=1$ なら探索を続ける。$J(D,n)=0$ の場合、$n \nmid i$ なら $1 < \gcd(i,n) < n$ であり、非自明因子を検出したので棄却する。$n \mid i$ の場合は因子が $n$ 全体である可能性があるため、その候補を飛ばす。この例外は、素数入力を誤って棄却しないために必要である。

<a id="square-and-termination"></a>

### 5.2 平方数と探索の停止

奇数の平方 $n=m^2$ では、$J(D,n)$ は $J(D,m)^2$ となり、$-1$ にはならない。したがってLucas側の探索を始める前に平方数を棄却する。論文は何個か候補を試してからの平方検査を提案しているが、先に検査しても受理条件は変わらない。

平方検査では整数平方根 $r=\lfloor\sqrt n\rfloor$ を求め、$r^2=n$ を判定する。浮動小数点の平方根による等号判定は使わない。剰余による事前棄却を行うなら、平方数の法8の剰余は $0,1,4$ なので、ビットマスク `0x13` を使える。奇数の平方の剰余は1だけである。

奇数の非平方 $n$ に対するJacobi指標は非自明で、$n$ と互いに素な整数 $a$ で $J(a,n)=-1$ となるものが存在する。実際、$n$ の素因数分解には奇数の指数を持つ素因子がある。その素因子の法では非平方剰余を、ほかの素因子の法では1を選び、中国剰余定理で組み合わせれば、Jacobi記号の積は $-1$ になる。

$a$ と同じ法 $n$ の剰余を持ち、法4で1となる十分大きい正整数を選べば、その整数自体が正の候補 $D$ になる。法4と法 $n$ は互いに素なので、この選択も中国剰余定理で可能である。よって全候補を順に調べる探索は、因子検出かJacobi値 $-1$ で停止する。この存在・停止にはRHやGRHを仮定しない。

実装で探索回数に上限を付ける場合、上限到達は「未判定」として扱う。Jacobi値 $-1$ がまだ見つからないことだけから合成数とは結論できない。

<a id="parameters"></a>

### 5.3 パラメータの選択

Method Aは、選択した $D$ に対して $P=1,Q=(1-D)/4$ とする。$D \equiv 1 \pmod 4$ なので $Q$ は整数である。

Method A*は、Method Aで $Q=-1$ となる場合、すなわち $D=5$ の場合だけ、$(P,Q)=(5,5)$ に置き換える。それ以外はMethod Aと同じである。置換後も $P^2-4Q=25-20=5$ なので判別式は変わらない。

素数入力で選択した $Q$ は $n$ と互いに素である。$D=5$ の置換では $J(5,n)=-1$ から $n\ne5$ が従う。その他では $P=1$ であり、仮に $n \mid Q$ なら $D \equiv 1 \pmod n$ となり、$J(D,n)=-1$ に反する。これにより、素数受理に使ったLucas命題の前提を満たす。

### 5.4 Method AとA*の同値性の範囲

両方法が異なるのは $D=5$ の場合だけである。この場合 $\gcd(n,10)=1$ であり、次の恒等式が成り立つ。

$$
U_{2k+1}(5,5)=5^kV_{2k+1}(1,-1),
$$

$$
V_{2k+1}(5,5)=5^{k+1}U_{2k+1}(1,-1),\qquad
V_{2k}(5,5)=5^kV_{2k}(1,-1).
$$

通常条件についても、偶数 $n+1$ に対して

$$
U_{n+1}(5,5)=5^{(n+1)/2}U_{n+1}(1,-1)
$$

が成り立つ。5の冪は法 $n$ で可逆なので、通常Lucas条件は同値である。強条件では奇数 $d_+$ における $U,V$ の役割が交換され、偶数添字の $V$ の零判定も保存される。したがって強Lucas条件も同値になる。

これらの恒等式は各組の特性方程式の根を使って導ける。$(1,-1)$ の根を $\alpha_1,\beta_1$、$(5,5)$ の根を $\alpha_2,\beta_2$ とすると、$\alpha_2=\sqrt5\alpha_1,\beta_2=-\sqrt5\beta_1$ である。前節の根による表示に代入すれば上の式を得る。

この同値性は、Lucas-V条件をMethod Aに置き換えてよいことまでは示さない。強化版ではMethod A*を保持する。

## 6. Lucas数列の二進法による計算

<a id="lucas-binary"></a>

### 6.1 共有する3つの値

添字 $k$ に対して $(u,v,q_k)=(U_k,V_k,Q^k) \bmod n$ を同時に求める。倍加には

$$
U_{2k}=U_kV_k,\qquad
V_{2k}=V_k^2-2Q^k,\qquad
Q^{2k}=(Q^k)^2
$$

を使う。添字を1増やすには

$$
U_{k+1}=\frac{PU_k+V_k}{2},\qquad
V_{k+1}=\frac{DU_k+PV_k}{2},\qquad
Q^{k+1}=Q Q^k
$$

を使う。これらは根による表示から従う整数の恒等式である。

添字0の初期値は $(0,2,1)$ である。正の $k$ では、二進表記の先頭の1を処理済みとして $(1,P,Q)$ から始めてもよい。残りのビットを上位から読み、毎回倍加し、そのビットが1なら添字を1増やす。処理した二進接頭辞を $m$ とすると、状態は常に $(U_m,V_m,Q^m) \bmod n$ である。

<a id="modular-halving"></a>

### 6.2 法の下での2除算と同時更新

奇数 $n$ では2は可逆である。剰余 $x_0=x\bmod n$ に対し、

$$
h_n(x)=\frac{x_0+(x_0\bmod2)n}{2}
$$

を計算すれば、$2h_n(x)\equiv x\pmod n$ となる。分子は必ず偶数で、結果も $0 \le h_n(x) < n$ に収まる。単に剰余を整数除算で2分すると、奇数の剰余を切り捨てて誤った値になる。

添字を1増やすときの $u,v$ は、どちらも更新前の $u,v$ から求める。C++では一時変数を使い、Pythonでは右辺を同時に評価する代入を使う。倍加の $v,q_k$ も更新前の $q_k$ を使う。

## 7. 通常版と強化版の判定手順

<a id="standard-procedure"></a>

### 7.1 通常版

1. $n=2$ は素数、$n < 2$ は素数ではない、2より大きい偶数は合成数と判定して終了する。
2. 底2の強Miller–Rabin条件を満たさなければ、$n$ は合成数と判定して終了する。
3. 平方数と分かったら、$n$ は合成数と判定して終了する。それ以外ではSelfridge探索を行い、非自明因子を検出したら、$n$ は合成数と判定して終了する。
4. Method A*で $P,Q$ を選ぶ。
5. 強Lucas条件を検査する。条件を満たしたら $n$ は確率的素数、満たさなければ合成数と判定して終了する。

強Lucasだけを調べる場合、$U_{d_+}=0$ なら直ちに受理できる。それ以外では $(V_{d_+},Q^{d_+})$ を倍加し、$r=0,\ldots,s_+-1$ の $V$ を調べる。0が見つかれば受理し、最後まで見つからなければ棄却する。$U$ は初項の検査後には更新しなくてよい。

<a id="enhanced-conditions"></a>

### 7.2 強化版の追加条件

強化版は通常版のすべての条件に加えて

$$
V_{n+1}\equiv2Q\pmod n,
$$

$$
Q^{(n+1)/2}\equiv QJ(Q,n)\pmod n
$$

を検査する。第2式はEuler条件 $Q^{(n-1)/2}\equiv J(Q,n)\pmod n$ に $Q$ を掛けた形である。

Eulerの判定法は、奇素数 $p$ と $p\nmid a$ に対して $a^{(p-1)/2}\equiv J(a,p)\pmod p$ を与える。有限体の非零元の巡回群で $a=g^t$ と書けば、左辺は $(-1)^t$ となり、$t$ が偶数であることと $a$ が平方剰余であることが同値なので従う。Method A*で選んだ $Q$ は素数入力と互いに素であるから、強化版のEuler条件でも素数を棄却しない。

強Lucas条件に成功しても、直ちに受理してはいけない。成功の有無をBoolean値 `strong_ok` に記録し、追加条件に必要な $V$ と $Q$ の冪まで計算を続ける。

<a id="enhanced-loop"></a>

### 7.3 最後の倍加とループの不変条件

初めに $(u,v,q_k)=(U_{d_+},V_{d_+},Q^{d_+})\bmod n$ を計算し、`strong_ok = (u == 0)` とする。以後 $u$ の更新は不要である。

各反復 $r=0,\ldots,s_+-1$ の入口では

$$
v=V_{d_+2^r}\bmod n,\qquad
q_k=Q^{d_+2^r}\bmod n
$$

が成り立つ。次の順で処理する。

1. $v=0$ なら `strong_ok` を真にする。
2. $v\leftarrow(v^2-2q_k)\bmod n$ と更新する。
3. 最後の反復なら終了する。それ以外では $q_k\leftarrow q_k^2\bmod n$ と更新する。

終了時には $v=V_{n+1}\bmod n$、$q_k=Q^{(n+1)/2}\bmod n$ になる。最後に $q_k$ を平方しないことで、Euler検査に使う半分の指数をそのまま保持できる。

強条件の零判定は必ず倍加前に行う。$V_{n+1}=0$ は強条件の添字範囲に含まれない。$s_+=1$ の場合も同じループで処理でき、$V_{d_+}$ を検査して1回だけ $V$ を倍加する。

<a id="q-coprime"></a>

### 7.4 Lucas-V受理から従う互いに素性

奇数 $n \ge 3$、$D=P^2-4Q$、$J(D,n)=-1$ のもとで、Lucas-V条件が成立すると $\gcd(Q,n)=1$ が従う。この命題には強Lucas条件を仮定しない。

証明のため、$Q,n$ の共通素因子を $\ell$ と仮定する。$J(D,n)=-1$ なので $\ell\nmid D$ である。$Q\equiv0\pmod\ell$ から $D\equiv P^2\pmod\ell$ となり、$P\not\equiv0\pmod\ell$ が従う。一方、Lucas漸化式は $k\ge1$ に対して $V_k\equiv P^k\pmod\ell$ を与える。Lucas-V条件なら $V_{n+1}\equiv2Q\equiv0\pmod\ell$ だが、$P^{n+1}$ は非零なので矛盾する。

したがって強化版では独立した $\gcd(Q,n)$ 検査を省ける。また、この段階を通過した後は $Q$ を合同式から消去できるので、乗算形Euler条件と通常のEuler条件は同値になる。実装では消去や逆元計算をせず、既に得た半指数の冪を使う。

固定した任意の $P,Q$ に対するLucas検査へ一般化する場合、素数受理の前提 $\gcd(n,Q)=1$ は別途確認する。パラメータ選択も判別式のJacobi検査も行わない下位関数に、BPSW全体の保証をそのまま適用してはいけない。

## 8. 計算例と実装上の選択

<a id="example-seven"></a>

### 8.1 素数7の強化Lucas計算

$n=7$ では $J(5,7)=-1$ なのでMethod A*は $(P,Q)=(5,5)$ を選ぶ。$n+1=8=2^3\cdot1$ であり、初期値は $(u,v,q_k)=(1,5,5)$ となる。

| 反復の入口 $r$ | 添字 | $v$ | $q_k$ | 強条件の零判定 |
|---|---|---|---|---|
| 0 | 1 | 5 | 5 | 失敗 |
| 1 | 2 | 1 | 4 | 失敗 |
| 2 | 4 | 0 | 2 | 成功 |

最後に $v=(0^2-2\cdot2)\bmod7=3$ とし、$q_k=2$ を保持する。$2Q\bmod7=3$、$QJ(Q,7)\bmod7=5(-1)\bmod7=2$ なので両追加条件を満たす。底2 MRも $2^3\equiv1\pmod7$ で成功し、7は受理される。

### 8.2 通常Lucasだけでは足りない例

論文の例 $n=323=17\cdot19$ では $D=P=Q=5$ であり、$n+1=324=2^2\cdot81$ となる。法323で $U_{81}=247,V_{81}=306,V_{162}=211$ なので強条件を満たさない。一方、$U_{324}=0$ なので通常Lucas条件は満たす。さらに $V_{324}=135\ne10=2Q$ なのでLucas-V条件にも失敗する。この例はLucas検査の違いを示すもので、BPSW全体を通過する例ではない。

### 8.3 候補探索の最適化

末尾の実装は候補を省かず、古典的な奇数列を調べる。公開C++・Python参考実装では、最初に絶対値 $5,7,9,11,13,15,17,19,23,29$ を調べ、その後は法30で $1,7,11,13,17,19,23,29$ の候補だけを使う。

この省略はJacobi値0による因子検出を含めた最初の停止を保つためのものである。9は因子3の検出を、$-15=(-3)\cdot5$ は、それ以前の $J(5,n)=1$ のもとで候補に現れない $-3$ の情報を補う。先行する候補がすべて継続した後では、3や5の倍数を記号の乗法性で除外できる。

この候補省略は論文の全奇数探索に加えた最適化である。純粋にJacobi値 $-1$ だけを探して0を無視する別仕様に、この省略の根拠をそのまま移してはいけない。移植時に候補省略の証明を使わない場合は、末尾の全奇数探索を採用すればよい。

### 8.4 費用と省略の条件

MRの二進累乗とLucasの二進計算は、それぞれ $O(\log n)$ 回の法乗算を行う。この回数には整数の乗算自体の費用とSelfridge探索を含めない。Lucas側は $U,V,Q^k$ を共有して計算し、強条件の後半では $U$ を省く。強化版は $s_+$ 回の $V$ 倍加を最後まで行うが、$V_{n+1}$ と半指数の冪を別々に計算し直す必要はない。早期受理する通常版に比べた追加費用は、受理が決まった位置によって変わる。

小素数による試し割りはMRの前に追加できる。$n$ がその小素数自身なら受理し、それ以外の倍数なら棄却する。公開参考実装と末尾の実装では、この効率化を省いている。

論文は、MR通過後に $\lvert Q\rvert$ が2の冪ならEuler検査は強さを追加しないと述べる。この省略を採用する場合は、符号付き2冪に対するEuler–Jacobi条件の導出まで確認する。強MRから符号を問わないEuler条件への帰結だけでは、Jacobi記号との一致を説明しきれない。特にLucas単体の検査には底2 MR通過の前提がない。ここに示す実装はすべての場合でEuler条件を検査する。

Leanの追加入口 `bpswWheel30ReducedEuler n true` は、奇数の $n > 1$ が底2 MRを通過し、`Nat.divMaxPow Q.natAbs 2 = 1` となる場合にEuler検査を省く。合同類や2冪の指数の偶奇による制限はない。奇数部分が1なら、2進付値による分解から $Q=\pm2^k$ が得られる。 $Q=\pm1$ も含み、 $Q=0$ はこの条件を満たさない。

$n\bmod4=3$ では $n-1$ の2進付値は1であり、MRの受理条件から半指数の冪が1または $-1$ となる。指数 $(n-1)/2$ は奇数なので、Jacobi記号の冪の公式で元の符号を取り出せる。1と $-1$ のJacobi値を使うと底2のEuler–Jacobi条件が得られ、冪と符号反転の保存則によって符号付き2冪にも適用できる。

2冪の指数が偶数なら $Q=\pm4^j$ と書ける。奇数の $n > 1$ では、MR通過から $2^{n-1}\equiv1\pmod n$ が得られ、$4^{(n-1)/2}\equiv1\pmod n$ となる。4のJacobi値も1なので、冪と符号反転の保存則によりEuler条件が成立する。この証明は $n\bmod4=1$ にも適用できる。[符号付き4冪の証明](#euler-signed-four-power-proof)では、MRの二つの受理経路と負のQを含めて導出する。

$n\bmod8=5$ の場合、$n-1$ の2進付値は2で、底2のJacobi値は−1、−1のJacobi値は1となる。MRの奇数指数 $d$ に対してJacobi値は $J(2^d,n)=J(2,n)=-1$ なので、$2^d$ が1または−1になることはない。MR通過時には残る添字1の段階、すなわち $2^{2d}\equiv-1\pmod n$ が成立し、$2d=(n-1)/2$ より底2のEuler条件が得られる。冪と符号反転の保存則により、符号付き2冪Qにも適用できる。

これらの枝では、一つのLucas状態からStrong条件と最終Vだけを判定する。半指数のQはVを倍加する計算でも必要なため、共有状態のQ更新は残る。Euler用のJacobi値と最終比較を省く実装であり、計算時間が短くなることは未測定である。条件を満たさない入力は従来の強化計算へ渡す。

[ConditionalEuler.lean](../PseudoPrime/PrimeTest/BPSW/ConditionalEuler.lean) は、すべての自然数・整数入力で従来のWheel30 Boolと一致することを証明する。Decisionと段階実行の入口も従来の結果と一致し、強化Boolは論文の5条件の仕様と一致する。追加入口を公開した段階であり、既定の入口とC++・Python実装は変更していない。$n\bmod8=1$ の枝も含めた[符号付き2冪全体の証明](#euler-signed-two-power-proof)は、次の節で示す。

論文のデータでは、Method A*のLucas-V擬素数は $10^{15}$ 未満で5個、強Lucas擬素数は474971個であった。これは追加検査を採用する動機となる有限計算の結果である。検査間の独立性や、任意の入力に対する誤受理確率はこの個数からは導けない。また、任意のパラメータで複数の条件を同時に満たす合成数があっても、Method A*がそのパラメータを選ばなければ強化BPSWの反例にはならない。

<a id="euler-signed-four-power-proof"></a>

### 8.5 底2 MR通過から符号付き4冪のEuler条件を導く証明

奇数の整数 $n > 1$ が底2の強Miller–Rabin検査を通過したとする。 $J(a,n)$ を整数 $a$ と奇数の法 $n$ に対するJacobi記号とする。このとき、任意の非負整数 $j$ と $Q=4^j$ または $Q=-4^j$ に対して、通常のEuler–Jacobi条件

$$
Q^{(n-1)/2}\equiv J(Q,n)\pmod n
$$

が成立する。さらに、両辺に $Q$ を掛けると、強化BPSWで使う乗算形Euler条件

$$
Q^{(n+1)/2}\equiv QJ(Q,n)\pmod n
$$

も成立する。素数性やLucas条件は仮定しない。

まず、MR通過からFermat条件を導く。 $n-1=2^s d$ と分解し、 $d$ を正の奇数、 $s\ge1$ とする。底2の強MRが通過するとは、 $2^d\equiv1\pmod n$、またはある整数 $r$ に対して $0\le r < s$ かつ $2^{2^r d}\equiv-1\pmod n$ となることである。

前者なら、合同式を $2^s$ 乗して

$$
2^{n-1}=(2^d)^{2^s}\equiv1\pmod n
$$

を得る。後者なら $s-r\ge1$ なので $2^{s-r}$ は偶数であり、

$$
2^{n-1}=(2^{2^r d})^{2^{s-r}}
\equiv(-1)^{2^{s-r}}=1\pmod n
$$

となる。したがって、どちらの受理経路でも $2^{n-1}\equiv1\pmod n$ が成立する。 $h=(n-1)/2$ と置けば、

$$
4^h=(2^2)^h=2^{n-1}\equiv1\pmod n
$$

が従う。

次に、必要なJacobi値を確認する。Jacobi記号は分子について乗法的であり、 $J(a^j,n)=J(a,n)^j$ が成り立つ。また、奇数の $n$ は2と互いに素なので、 $J(2,n)$ は1または−1である。よって

$$
J(4,n)=J(2^2,n)=J(2,n)^2=1
$$

となる。負の分子には補充法則

$$
J(-1,n)=(-1)^{(n-1)/2}=(-1)^h
$$

を使う。この式は合成数にも成立する。実際、重複を含む素因数分解を $n=p_1\cdots p_t$ と書くと、Jacobi記号の定義と素数に対する補充法則から $J(-1,n)=\prod_{i=1}^t(-1)^{(p_i-1)/2}$ を得る。奇数 $a,b$ では $(ab-1)/2$ と $(a-1)/2+(b-1)/2$ の差が $(a-1)(b-1)/2$ という偶数になるため、積の符号は $(-1)^{(n-1)/2}$ と一致する。

$Q=4^j$ の場合、

$$
Q^h=(4^h)^j\equiv1\pmod n,
\qquad
J(Q,n)=J(4,n)^j=1
$$

なのでEuler–Jacobi条件が成立する。 $Q=-4^j$ の場合も、

$$
Q^h=(-1)^h(4^h)^j\equiv(-1)^h\pmod n,
\qquad
J(Q,n)=J(-1,n)J(4,n)^j=(-1)^h
$$

となり、両辺は一致する。これで符号付き4冪の両方を証明した。 $j=0$、すなわち $Q=1$ と $Q=-1$ も含む。

最後に、 $h+1=(n+1)/2$ なので、得た合同式の両辺に $Q$ を掛ければ乗算形Euler条件を得る。この方向では $Q$ による約分や逆元計算は必要ない。したがって、底2 MR通過後に $Q=\pm4^j$ と確認できた場合、通常形と乗算形のどちらのEuler検査も新たな不受理を生まない。

<a id="euler-signed-two-power-proof"></a>

### 8.6 符号付き2冪全体への拡張

奇数の $n > 1$ が底2の強MRを通過した場合、任意の非負整数 $k$ と $Q=2^k$ または $Q=-2^k$ に対しても、Euler–Jacobi条件が成立する。底2自身の条件

$$
2^{(n-1)/2}\equiv J(2,n)\pmod n
$$

を証明すれば、Jacobi記号の冪の公式と負の分子の補充法則で、符号付き2冪全体へ広げられる。

奇数の合同類は、 $n\bmod4=3$、 $n\bmod8=5$、 $n\bmod8=1$ の三つに分けられる。最初の二つの枝の導出は8.4節に示した。残る $n\bmod8=1$ では $J(2,n)=1$ なので、底2の半指数冪が1になることを証明する。

$n-1=2^s d$ と分解し、 $d$ を正の奇数とする。この合同類では $s\ge3$ である。MRの最後の−1受理段階、すなわち

$$
2^{2^{s-1}d}\equiv-1\pmod n
$$

が起こると仮定し、矛盾を導く。

まず、奇素数 $p$ に対する指数の上界を確認する。 $p-1=2^t c$、 $c$ は奇数とし、非零の法pの剰余 $y$ が $y^{2^u m}\equiv-1\pmod p$ を満たすとする。このとき $u < t$ が必要である。もし $u\ge t$ なら、Fermatの小定理から

$$
(y^{2^u m})^c
=y^{(p-1)2^{u-t}m}\equiv1\pmod p
$$

となるが、左辺は奇数 $c$ 乗の $-1$、すなわち $-1$ でもある。奇素数を法として1と−1は異なるので矛盾する。

$n$ の任意の素因子を $p$ とする。 $n$ は奇数なので $p$ も奇素数であり、仮定した合同式は法pにも成立する。上の指数上界を $y=2,u=s-1,m=d$ に適用すると、 $s\le t$ を得る。したがって $2^s\mid p-1$ であり、 $s\ge3$ より $p\bmod8=1$ となる。

ここで、2に対する二次剰余の補充法則を使う。奇素数 $p$ に対して $p\bmod8=1$ なら2は非零の平方剰余であるため、 $y^2\equiv2\pmod p$ を満たす非零の剰余 $y$ が存在する。この平方根を仮定した合同式へ代入すると、

$$
y^{2^s d}=(y^2)^{2^{s-1}d}
\equiv2^{2^{s-1}d}\equiv-1\pmod p
$$

となる。今度は指数上界を $u=s,m=d$ に適用できるので、 $s < t$、すなわち

$$
2^{s+1}\mid p-1
$$

を得る。

これは $n$ のすべての素因子に成立する。重複を含む素因数分解を $n=p_1\cdots p_r$ と書けば、各 $p_i$ が法 $2^{s+1}$ で1に合同なので、その積 $n$ も1に合同である。よって $2^{s+1}\mid n-1$ となる。しかし、 $s$ は $n-1$ の2進付値として選んでいるため矛盾する。これで、最後の−1受理段階を排除できた。

MRが初期の $2^d\equiv1\pmod n$ で受理された場合は、 $2^{s-1}$ 乗して半指数冪が1になる。−1の段階で受理された場合も、その添字 $u$ は最後より小さいので、 $u < s-1$ である。残る指数 $2^{s-1-u}$ は偶数であり、

$$
2^{(n-1)/2}
=(2^{2^u d})^{2^{s-1-u}}
\equiv(-1)^{2^{s-1-u}}=1\pmod n
$$

となる。したがって $n\bmod8=1$ の枝でも $2^{(n-1)/2}\equiv J(2,n)\pmod n$ が成立し、三つの合同類をすべて証明した。

最後に $h=(n-1)/2$ と置く。 $Q=2^k$ なら $Q^h\equiv J(2,n)^k=J(Q,n)\pmod n$ である。 $Q=-2^k$ でも、両辺に同じ符号 $(-1)^h=J(-1,n)$ が掛かるため一致する。指数0と両符号を含めて、符号付き2冪全体のEuler条件が得られた。両辺に $Q$ を掛ければ乗算形Euler条件も従う。法nでの素数性やLucas受理は仮定しない。

## 9. 単独で実行できるPython実装

以下はPythonの多倍長整数、整数平方根 `math.isqrt`、法累乗 `pow(a,d,n)` を使う。本文の更新式と停止条件を直接実装している。候補探索には全奇数列を使い、追加のWheel30最適化は行わない。`bpsw(n)` が通常版、`bpsw(n, enhanced=True)` が強化版である。

```python
from math import isqrt


def v2(x):
    assert x > 0
    return (x & -x).bit_length() - 1


def jacobi(a, n):
    assert n > 0 and n % 2 == 1
    a %= n
    sign = 1
    while a:
        while a % 2 == 0:
            a //= 2
            if n % 8 in (3, 5):
                sign = -sign
        if a % 4 == n % 4 == 3:
            sign = -sign
        a, n = n % a, a
    return sign if n == 1 else 0


def mr2(n):
    assert n >= 3 and n % 2 == 1
    s = v2(n - 1)
    d = (n - 1) >> s
    t = pow(2, d, n)
    if t == 1:
        return True
    for j in range(s):
        if t == n - 1:
            return True
        if j == s - 1:
            return False
        t = t * t % n


def params_a_star(n):
    assert n >= 3 and n % 2 == 1
    if isqrt(n) ** 2 == n:
        return None
    i = 5
    while True:
        D = i if i % 4 == 1 else -i
        j = jacobi(D, n)
        if j == -1:
            return (5, 5) if D == 5 else (1, (1 - D) // 4)
        if j == 0 and i % n != 0:
            return None
        i += 2


def half_mod(x, n):
    x %= n
    return (x + (x % 2) * n) // 2


def lucas_uvq(n, P, Q, k):
    assert n > 0 and n % 2 == 1 and k >= 0
    if k == 0:
        return 0, 2 % n, 1 % n
    D = P * P - 4 * Q
    u, v, qk = 1 % n, P % n, Q % n
    for bit in range(k.bit_length() - 2, -1, -1):
        u, v, qk = u * v % n, (v * v - 2 * qk) % n, qk * qk % n
        if (k >> bit) & 1:
            u, v, qk = (
                half_mod(P * u + v, n),
                half_mod(D * u + P * v, n),
                Q * qk % n,
            )
    return u, v, qk


def lucas_check(n, P, Q, enhanced):
    assert n >= 3 and n % 2 == 1
    # 呼び出し側でJ(P^2 - 4Q, n) = -1となるパラメータを選ぶ。
    s = v2(n + 1)
    d = (n + 1) >> s
    u, v, qk = lucas_uvq(n, P, Q, d)
    strong_ok = u == 0
    if not enhanced and strong_ok:
        return True
    for r in range(s):
        if v == 0:
            strong_ok = True
        if not enhanced:
            if strong_ok:
                return True
            if r == s - 1:
                return False
        v = (v * v - 2 * qk) % n
        if r == s - 1:
            break
        qk = qk * qk % n
    return (
        strong_ok
        and v == (2 * Q) % n
        and qk == (Q * jacobi(Q, n)) % n
    )


def bpsw(n, enhanced=False):
    if n == 2:
        return True
    if n < 2 or n % 2 == 0:
        return False
    if not mr2(n):
        return False
    params = params_a_star(n)
    if params is None:
        return False
    return lucas_check(n, *params, enhanced)
```

負の剰余を返す言語へ移植する場合は、各剰余を $0 \le r < n$ に正規化する。固定幅整数を使う場合は、$n+1$、$P^2-4Q$、法を取る前の積にも十分な範囲を確保する。C++の公開参考実装は多倍長整数を使い、添字とビット位置の容量にも検査を設けている。

## 10. 論文・公開実装・Lean証明の位置付け

本文の数列と合同式は、次の論文の実装に必要な部分を再構成したものである。

Robert Baillie, Andrew Fiori, Samuel S. Wagstaff, Jr., *Strengthening the Baillie–PSW primality test*, arXiv:2006.14425v2。通常・強Lucasと二進計算は第2節、通常BPSWは第3節、強化版の5段階は第6節、Method AとA*の同値性は付録に対応する。第7節の確率的考察は追加検査の動機であり、素数受理や探索停止の証明には使わない。

公開C++・Python版も底2 MR、Method A*、強Lucas、Lucas-V、乗算形Eulerの順を採用する。本文の独立実装との主な違いは、Wheel30による候補省略と算術補助関数の実装方法である。通常版と強化版の公開関数の使い方は [BPSW参考実装](BPSWImplementations.md) にまとめている。

Leanでは素数受理、Lucasの更新式、算術補助関数や一部の実行手順の整合性を証明している。これらと、C++・Pythonプログラム全体の同値証明、任意の受理入力の素数性はそれぞれ別の主張である。本ページはそれらの未証明部分を完成したとは主張しない。公開APIの説明は [PrimeTest](PrimeTest.md)、文書全体の入口は [README](README.md) にある。
